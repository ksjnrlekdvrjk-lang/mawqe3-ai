# موقع AI — الجزء الأول

نسخة واجهة محرر مواقع عربية RTL مبنية على Next.js.

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح:
http://localhost:3000

## ملاحظات
- هذه النسخة هي أساس المحرر وليست Backend إنتاجي.
- Google Translate مدمج كأداة ترجمة للواجهة/المعاينة عبر سكربت Google Translate.
- الذكاء الاصطناعي في هذه النسخة تجريبي محلي (أوامر بسيطة) حتى نضيف API آمن في الجزء الثاني.
- لاحقًا نضيف قاعدة البيانات والحسابات والحفظ الحقيقي والاستضافة والسوق.
